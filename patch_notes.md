## 🏘️ Once Upon a Town v0.0.9 [Beta]
### Herd system:
- As the active residents system, there is now a system for active herd into the village. Each animal field you are going to place in the village is going to consume food units once a day
- Evolving your animal farms are going to add more resources produced but also cost you more food units scaling over time
- The idea is to add soft pressure in the early game and improve the management aspect of the mod in the late game, making gameplan more rewarding
### Features:
- The food consumed by the animals and the NPC is now a 100% datadriven system, allowing modded food resources
- The quest is also a 100% datadriven system now, each quest can be customize in it's dedicated config JSON file
### Bug fixing:
- Reworked the road placement system that should allow way more roads to be built, making the early game smoother
- Cleaned a ton of files to optimize the system
### Added building:
- New street variant 7
